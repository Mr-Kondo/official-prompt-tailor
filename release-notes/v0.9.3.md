# v0.9.3

## 変更点

Skills CLIへの初回登録と、`npx skills update` によるmain最新版への更新手順を追加しました。既存のPythonインストーラ、タグ固定、ZIP・プラグイン配布も引き続き利用できます。

- READMEと導入文書に、取得元登録・更新・移行時の退避・削除・製品ごとの配置の違いを記載。
- スキルフォルダへVERSIONを同梱し、公開版との一致をテスト。
- プロンプト最適化の規則・実行処理は変更していません。

## 確認できていること

- 既存の回帰試験とVERSIONの整合検査。
- Skills CLI 1.7.6でのスキル探索、隔離環境でのGitHub/main登録、変更がない場合の更新、配布元とのファイル照合。

## 確認できていないこと

各製品の自然言語によるスキル起動・プロンプト最適化品質は、この配布経路の変更では再評価していません。Skills CLIはmainに追従するため、公開タグと同じ版に固定するものではありません。
