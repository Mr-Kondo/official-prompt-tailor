# v0.10.0

## 変更点

`install.py` を廃止しました。導入・更新・削除は Skills CLI（`npx skills add` / `update` / `remove`）だけになります。

- `install.py`、ZIP 出力（Claude Cowork 向け）、プラグイン出力（ChatGPT Work 向け）を削除。必要な場合は v0.9.3 までのタグの `install.py` を使えます。
- GitHub Release に ZIP を付けなくなりました。版の出どころはスキルフォルダの `VERSION` だけです。
- README・導入文書・保守文書から、`install.py` の手順を除去。v0.9.3 までで導入した既存コピーの移行手順は残しています。
- プロンプト最適化の規則・実行処理は変更していません。
