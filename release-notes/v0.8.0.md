# v0.8.0

## 変更点

- 資料に別形式の URL(`alternates`)を持たせられるようにした。`fetch` は、最初のページが読めなかったときだけ、同じホストの別形式(`.md` 版など)を順に試し、読めた組を `acquisition.json` の `requested_url`・`final_url`・`extraction_version` に残す。どれも読めないときは、最初のページのエラーを返す。`drift`・`rereview`・`adopt` は、最初のページだけを見る。
- 規則に、省略できる `alt_body_sha256` を足した。別形式の本文に引用がある規則だけ、別形式から読んだ本文でも使える(1つ目のページの `drift` には効かない)。別形式は1つ目と同じホストに限る。引用がない規則は、別形式を読んだ run で再審査待ち(`rereview_pending`)になり、`PASS_LIVE` にならない。
- メンテナー用に `tools/maintain.py alternates` を追加した。別形式の登録と `alt_body_sha256` の記録を行う(手順は `docs/maintenance.md`)。
- `claude-code-best-practices` に `https://code.claude.com/docs/en/best-practices.md` を追加した。
- `adr/0002-alternate-urls-per-source.md` に、この決定を記録した(ADR 0001 の決定7を実装)。
