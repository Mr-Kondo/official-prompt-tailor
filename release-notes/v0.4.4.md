`v0.4.3` からの変更は、`claude-cowork-projects`(`support.claude.com` の記事)の `drift` が、公式資料の内容が変わっていないのに `changed` を出し続けていた問題の修正です。

## 変更点
スキル本体(添付の ZIP に入るもの):
- `scripts/evidence.py`: 取り出し方 `markdown-v2` を足しました。`markdown-v1` から、署名付き画像のクエリ(`?expires=…&signature=…&req=…`)を除いたものです。`markdown-v1` と、ほかの取り出し方は変えていません。署名のない画像、通常のリンク、`signature=` を含むリンクは、そのまま残ります。
- `references/registry.json`:
  - 資料 `claude-cowork-projects` の `extraction` を `markdown-v2` にしました。ほかの資料は変えていません。
  - 規則 `claude-cowork-project-instructions` を再審査しました。更新したのは、`source_body_sha256`・`reviewed_at`・`reviewer_id` の 3 項目だけで、規則の意味と範囲は変えていません。`reviewer_id` は `Claude Code agent (claude-sonnet-5-5) re-review 2026-10-16: …; not human` です。旧本文が残っていなかったため、引用とその前後を、いまの本文で読んで確かめました。

保守用(ZIP には入らないもの):
- `tools/maintain.py`: `propose` が、署名付き画像のある Markdown に `markdown-v2` を選びます。
- `docs/maintenance.md`: `markdown-v2` の説明を足しました。
- `--plugin` が作るマニフェストの `version` を `0.4.4` にしました。

## 原因
`support.claude.com` は、記事の画像に署名を付け、1 時間ごとに付け直します(`expires` が 00:15Z から 01:00Z に変わるのを確認しました)。署名が本文に入っていたため、記事が変わっていなくても、本文のハッシュが 1 時間ごとに変わりました。その結果、`drift` が `DRIFT` を出し、規則は `changed` になりました。SKILL.md の手順は `changed` の規則を選ばないので、Claude Cowork の `persistent-instructions` で、この規則が使えない状態でした。

## 確認できていること
- テスト 268 件が、手元の Python 3.13 で通ります(ネットワークは mock)。`markdown-v2` が署名の違う 2 つの本文から同じハッシュを出すこと、署名付きでない本文が `markdown-v1` と一致すること、悪意のある入力で線形時間であることを、テストしました。
- 手元で、実際の記事に対して `drift` が `CURRENT` でした(2 回続けて一致)。
- 取得できた Anthropic の 26 資料のうち、本文に署名付き URL があったのは、この 1 件だけです。

## 確認できていないこと・既知の問題
- 署名が切り替わったあとも、`markdown-v2` の本文のハッシュは変わりませんでした。00:22Z に署名の期限が `01:00Z` へ、04:58Z には `05:30Z` へ切り替わっています。`markdown-v2` のハッシュは `9a2f2d32f94c…` のままで、`drift` は `CURRENT` でした。`markdown-v1` のハッシュは、`6f1e8969…`(23:50Z)、`3f10d7a9…`(00:22Z)、`512422a4…`(04:58Z)と変わりました。
- ZIP は 6 ファイル、304,108 B です。手元の SHA-256 は `693f325f9df3c9ef06f426278d89fcde46fec8c932a068433df7a342b8f08dd5` です(GitHub Actions での照合は、PR の CI のあとに行います)。
- 取得できなかった Google・OpenAI の 24 資料に、署名付き URL があるかは、この環境から確かめていません。GitHub Actions の `watch` の実行では、`drift` はこの 1 件だけでした。
- 規則の再審査は、Claude Code のエージェントが行ったもので、人の審査は 0 件です。旧本文との比較はできていません。
- 画像のクエリを除いても本文の意味は変わらない、という判断は、画像の説明文が空(`![]`)であることにもとづく、私の判断です。
- このほかは `v0.4.3` から変わっていません(意味審査と効果測定が未実施、資料が 0 件の入力と取得できる入力の別エージェントによる確認が一部であること、など)。
