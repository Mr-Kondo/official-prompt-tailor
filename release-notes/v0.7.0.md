# v0.7.0

## 変更点

- 公式資料が一部取れなくても、取れた資料で最適化を続けられるようにした。`fetch` は、一部だけ取得できたとき終了コード3を返し(取得0件は従来どおり2)、標準出力に `coverage`(取れた資料・取れなかった資料と理由・許可が要るホスト)と `model_hint` を出す。結果は候補で、`PASS_LIVE` にはならない。
- Claude チャット・Claude Cowork・Claude Code で、`model_id` が登録と一致すれば、`target_surface` が `unknown` でもモデル別ガイドを取得する。モデル別の規則33件の `surfaces` を `all` にした(規則の意味と引用は変えていない)。「Sonnet5.5」のような書き方にも、`model_hint` が登録済みの ID を示す。
- live で取れなかった資料を、同じ場所にある7日以内の前の run の取得物(`cache`)で自動的に補う。
- ホストが検索で見つけた公式ドメインのページを、`fetch --extra-source <URL>` で渡せるようにした。結果は run の `discovered-sources.json` に残り、`registry.json` は書き換えない。そのページを引用する変更は `kind: candidate` で、参照検証は `INCOMPLETE`(`candidate_source_unreviewed`)になる。
- `sources --markdown` に、取得できなかった資料と「公式候補(未審査)」を出すようにした(書式の版を 5 に上げた)。
- メンテナー用に `tools/maintain.py intake --run <run>` を追加した。検索で見つけた未登録のページを Issue の下書きにする。
- `adr/0001-partial-evidence-and-search-fallback.md` に、この決定を記録した。

## 確認できていること

- 全テストが通る(新規テストを含む)。
- 見送った項目: 別形式 URL への切り替え(切り替え先を持つ資料が登録簿にないため)。理由は ADR に記録した。
