## 変更点
- `docs/targets.md` を追加しました。利用先 11 種ごとの取得資料、使える規則の件数、`purpose` / `target_surface` / `model_id` の決め方をまとめています。
- `docs/maintenance.md` に「資料の更新と追加を取り込む」を追加しました。更新の確かめ方(取得した本文のハッシュと、規則に記録したハッシュの比較)と、新しい資料・利用先の足し方を書いています。現状は、どちらも手作業です。
- README から、上の 2 文書へのリンクを足しました。
- `--plugin` が作るマニフェストの `version` を `0.1.3` にしました。

## 確認できていること
- テスト 110 件が通ります(ネットワークは mock)。Python 3.10〜3.15 で確認しました。
- `docs/targets.md` の資料と規則の表は、`registry.json` から計算した値と一致します。
- README と `docs/` の相対リンク(ファイルとアンカー)は、すべて解決します。
- `docs/maintenance.md` の比較コマンドと、資料の追加手順は、実際の取得(live)で動作を確認しました。
- 2026-10-15 の確認で、取得できた 19 資料のうち、規則のある 18 資料の本文ハッシュは、審査時(2026-10-14)と一致しました。

## 確認できていないこと・既知の問題
- Python 3.9 では、`fetch` と `install.py` の一部(`--plugin`、`--gitignore`)が動きません。`Path.write_text` の `newline` 引数が、3.10 以降のためです。README の「Python 3.9 以上」は、このリリースでは満たしていません。
- 2026-10-15 の確認では、`developers.openai.com` の資料(`openai-api-prompting`)が HTTP 403(ボット検査)で取得できませんでした。`target_surface` を `api` にした OpenAI 系の利用先に影響します。
- Claude Cowork と ChatGPT Work では動かしていません。ChatGPT Work へのプラグインの取り込み方は、公式資料で確認できていません。
- 読取りの観測ができるのは Claude Code だけです。他の製品では、参照検証は最良でも `INCOMPLETE` になります。
- 意味審査と効果測定は未実施です。
