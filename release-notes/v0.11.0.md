# v0.11.0

## 変更点

公式資料の更新を取り込みました。登録は資料52件・規則113件(これまで50件・103件)です。

- **Claude Fable 5.2**: 公式ガイド `claude-prompting-fable-5-2` を足し、規則5件を採用(最後までやり切る・コードの所有を伝える・一行の途中報告・例外のない規則に範囲と理由を書く・最終報告は単独で分かるように書く)。汎用ガイド `claude-model-prompting` の対象モデルにも `claude-fable-5-2` を加えました。
- **OpenAI GPT-6**: 公式ガイド `openai-gpt-6-prompting`(「Using GPT-6」)を足し、Codex 向けの規則5件を採用(承認は具体的な成果を用意してから・利用者の指示とスキルの優先順位・文体の指定・サブエージェントの委任・テスト量の見積もり)。
- **Gemini API**: 公式ページが `aistudio.google.com` へ移っていたため、取得先を新しい `.md` に変えました(取得形式は `markdown-v1`)。引用は、行の折り返しに合わせて1行に収まる文に直しました。
- **再審査**: 本文が変わった46規則を再審査しました。引用と前後が同じ40規則は機械で更新し、6規則(`claude-chat-*` 3件、`claude-fable-5-1-no-reasoning-echo`、`antigravity-cli-rule-file-contents`、`gemini-api-clear-specific`)は差分を読んで更新しました。意味と適用範囲は変えていません。
- 新規ページ候補21件は、規則にできる助言がないため既読にしました。
