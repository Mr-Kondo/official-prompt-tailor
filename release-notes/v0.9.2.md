# v0.9.2

## 変更点

- HTML を前提にした資料の取得で、`Accept` に `text/html` だけを送るようにしました。ai.google.dev が、`text/markdown` を含む `Accept` に Markdown で答えるようになり、`gemini-api-prompting` が `unexpected_content_type:text/markdown` で取得拒否されていました。Markdown を前提にした資料の取得は変えていません。
- 公式資料の更新に合わせて、規則 8 件を再審査しました（`codex-skill-description-scope`、`claude-chat-clear-ask`、`claude-chat-context`、`claude-chat-substeps`、`antigravity-rules-persistent`、`antigravity-skill-description`、`antigravity-skill-focused`、`openai-api-instructions-param`）。更新したのは審査の日時・審査者・本文のハッシュだけで、規則の意味と適用範囲は変えていません。

## 確認できていること

- 全体 408 件のローカル回帰試験と CI 全ジョブが成功しました。
- リリース直前の `drift` は CURRENT でした。取得できない資料は 0 件です。
- Codex のコードレビューを 2 回行いました。1 回目の指摘（Markdown 資料の `Accept` が未検証）は採用し、テストを直しました。2 回目は指摘なしでした。人手審査ではありません。
- 8 件のうち 7 件は、引用とその前後が変わらないことを `rereview` が確かめました。`antigravity-rules-persistent` は、差分を読み、探索範囲とパスの表記だけが変わったと判断して更新しました。

## 確認できていないこと

- 資料の本文が変わったことによる、利用時の判断の質への影響は未測定です。再審査は、引用とその前後が変わらないことの確認で、意味の変化の判定ではありません。
- `Accept` を `text/html` だけにしたことで、ほかのサイトの応答が変わる可能性は、今回の取得で見た範囲（登録済みの全資料が取得できたこと）でしか確かめていません。
