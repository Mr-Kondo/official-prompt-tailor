# v0.9.0

## 変更点

- WikiSkillの三層分離を更新管理へ限定導入。保守用の知見記録・索引・整合検査を追加しました。
- スキル自体の更新時だけ読む手順を追加。通常のプロンプト最適化に知見を注入しません。
- 既存のIssue・ADR・評価への参照を再利用し、根拠の状態と採否・理由を分けます。

## 確認できていること

- 検査は通信せず、形式・参照・索引・採用の前提を確認します。標準ライブラリのみです。
- 保守用の知見・索引・ツールは配布物へ含めず、更新手順だけを既存インストーラーで配布します。

## 確認できていないこと

- 実運用での探索時間削減、品質向上、維持費削減は未測定です。

- Issue #24の利用者フィードバック受付機能と、#7の実モデル効果測定は本リリースに含みません。
